# Filigrana Digital

Static bilingual website (Norwegian and English).

## GitHub Pages preview

The site is published at <https://yulian47.github.io/Filigrana-Digital/> from
the root of the `main` branch.

The site is served from a project subpath, so internal links and assets should
remain relative. `_headers` and `_redirects` are retained for compatible static
hosts; GitHub Pages does not apply those files.
